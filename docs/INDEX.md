## 按生命周期

| 状态 | 含义 | 典型文档 |
|---|---|---|
| 稳定 | 长期有效，改动需评审 | 架构总览、模块模板、注释规范 |
| 当前 | 随分支变化，以代码为准 | 接口约定、源码导航、版本记录 |
| 历史 | 只归档不改，保留当时结论 | I* 迭代方案、R* 联合验收、旧验收记录 |

## 维护规则

1. 一份事实只写一处：能力看首页，验证看[版本记录](40-operations/status.md)，规则看业务域文档。
2. 新建文档必须带四行元信息：类型、状态、适用版本、责任模块。
3. 历史文档移入[归档](90-archive/README.md)而不是删除；当前文档不反向依赖归档。
4. 新增页面或控制器后运行 `node scripts/checks/docs/check.mjs --write-index`；提交前运行 `node scripts/checks/docs/check.mjs`。

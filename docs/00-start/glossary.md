# 术语表

> 类型：参考 | 状态：稳定 | 适用：0.1 开发分支 | 责任：平台组

| 术语 | 含义 | 常见误解 |
|---|---|---|
| 到货通知 | 采购安排送达后在 WMS 生成的待收货单 | 不是收货单，本身不动库存 |
| 收货草稿 | 可编辑、未过账的收货单 | 草稿不占库存、不写流水 |
| 提交收货 | 写余额、流水与待发消息的时点 | 提交后不可改，只能冲正 |
| 质检 | 对待检库存判定合格/不合格 | 判定会移动余额，不是打标记 |
| 上架 | 从待检区移动到正式库位 | 只有合格品可上架 |
| 预占 | 锁定可用量（available），不动在库量 | 预占失败不等于库存不足 |
| 发料 | 原料仓到线边仓的移动 | 总库存不变，只是位置变化 |
| 消耗 | 线边库存真正减少 | 只有消耗才降低全仓总量 |
| 冲正 | 用反向记录抵消已提交事实 | 不修改原记录，保留历史 |
| 结案 | 用事实摘要确认数量履约完成 | 不等于金额或成本结清 |
| 事实哈希 | 结案依据的摘要值 | 并发变更导致冲突是保护，不是故障 |
| Outbox / Inbox | 本地事务内记录待发/已收消息 | 发布成功不等于对方已处理 |
| 版本（version） | 乐观锁，防止覆盖 | 不是幂等键，两者不能互相替代 |
| 幂等键 | 标识“同一次提交”的请求标识 | 失败后不能换新键重试 |
| 数据范围 | 账号可见的仓库或组织 | 不是角色，不能靠角色替代 |

# MES 反馈、生产消耗与退料闭环

## 已确认范围

承接生产领料首版，完成三个环节：发料结果可靠反馈；依据模拟 MES 回传确认生产消耗；依据模拟 MES 退料需求，在仓管确认实物后将余料退回原料仓。仅使用项目内模拟系统，不配置真实 MES，不合并待审批 PR。

## 库存与业务约束

- 已发料物料按领料单、工单、批次保留线边归属。线边生产占用量独立于原料预占，可用量=现存量-预占量-生产占用量。普通移库和盘点不能动用生产占用量。
- 消耗只依据 local/test 管理员模拟 MES 回传；相同外部事件号必须同内容，重复不扣账。消耗减少线边现存与生产占用，并形成不可变流水和结果反馈。
- 单据剩余=领料量-已消耗-已退回；可消耗/新申请退料额度还需扣除待确认退料。消耗、退料申请、取消和确认串行校验额度，防止竞争超用。
- 退料申请不改实存，仓管核对实物、数量、质量和目标库位后确认。合格且未过期余料退回原料仓 STORAGE；不合格或过期物料仅允许按 REJECTED 退入 INSPECTION 隔离，不增加可用量。
- 待确认退料可取消并释放额度；已确认退料和已记录消耗不可修改或删除。首版不含消耗冲正、已退单冲正、跨领料单调剂和部分发料。

## 可靠反馈方案

扩展现有 Outbox 的业务来源约束，保留收货外键保护并增加领料来源；发料/消耗/退料与反馈事件同事务。沿用现有租约、指数退避、发布确认和管理员带原因重放，不另建平行消息调度器。

新增模拟 MES 接收队列和死信隔离；按业务事件身份去重且核对原内容。发布完成与模拟 MES 接收分开显示，不能将发布成功解释为对方已处理。消息乱序不回写 WMS 库存，也不覆盖已有业务记录。

## 升级与验收

新增迁移为旧已发料库存回填生产占用；若历史线边库存已移动或盘亏导致不足，迁移应失败并要求先核对，不虚构库存补差。升级前备份，旧程序不得继续写入新模型。仅在隔离环境应用迁移，日常数据库升级留待统一审批。

覆盖正常/重复/冲突消息、并发消耗与退料竞争、跨工单额度、失败重试与重放、事务回滚、双仓权限、隔离退料及历史收货回归；前端使用内置浏览器验收，扩展库存对账后提交依赖 #19 的 PR。

## 接口与权限

| 入口 | 用途 | 权限 |
|---|---|---|
| GET /api/v1/wms/production/issues/{id} | 领料归属、消耗、退料、待退额度 | wms:production:read |
| GET /api/v1/wms/production/issues/{id}/records | 消耗/退料记录，returns=true 为退料，分页从 0 起 | wms:production:read |
| POST /api/v1/wms/production/returns/{id}/confirm | 确认实际退回 | wms:production:confirm |
| POST /api/v1/wms/production/returns/{id}/cancel | 带原因取消待退单 | wms:production:cancel |
| GET /api/integration/material-issues/{id}/feedback | 发布状态及模拟 MES 接收时间 | wms:issue:read 或 wms:production:read |
| POST /api/local/mes-production/consumptions | 模拟 MES 实际消耗 | local/test + ADMIN |
| POST /api/local/mes-production/returns | 模拟 MES 退料需求 | local/test + ADMIN |

非管理员还需原料仓与线边仓两个 wms:warehouse:{id} 数据权限。页面从领料单进入时需领料查询权限，选择库位需 warehouse:read。新增生产权限加入白名单，不自动扩大已有操作员权限；所有写请求保留 CSRF 校验。

事件号为 1–64 位字母、数字、横线或下划线，区分大小写；数量最多 12 位整数和 6 位小数。重试必须保留事件号、工单、数量和退料内容，内容不同返回冲突。消耗和退料分别保存事件身份。消息发布失败沿用 /messages 带原因重放，重放不重新扣库存。

## 迁移与回退边界

新增 V202610070003（发料反馈及旧单补反馈）、V202610070004（模拟 MES 业务去重）、V202610070005（生产归属及消耗/退料）。MySQL DDL 不保证整组事务回滚，升级失败时应停止服务、保存故障证据并基于升级前备份恢复，禁止直接启动旧代码继续写库。已发料库存的占用回填只改变可用/归属量，不增加库存和流水。

真实 MES 的身份鉴别、消息入口、契约对接和生产部署不在此次范围；local/test 模拟入口不得当作外部系统生产接口。消耗/已确认退料的冲正、异常补料、跨工单调剂和报废须后续独立设计。

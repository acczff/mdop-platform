# 生产领料首版

> 本文保留 #19 首版验收记录。后续切片见[生产消耗与退料闭环](生产消耗与退料闭环.md)：线边发料改为生产占用而非自由可用量，并新增 MES 可靠反馈、实际消耗和余料退回；以下历史记录不代表当前分支仍缺少这些能力。

## 范围与边界

模拟 MES 按工单和需求号下发单物料需求，WMS 选择一个原材料仓库存维度整单预占，仓管确认实际发料后转入指定线边仓正式库位。总库存不变；实际生产消耗、BOM 替代、超领与部分发料不在本版范围。模拟入口只在 local/test 环境开放，限管理员；没有真实 MES 对接或自动启用外部平台。

## 状态与记账

- 待预占 OPEN → 已预占 RESERVED → 已发料 ISSUED；OPEN/RESERVED 可取消 CANCELLED，终态不可修改。
- 预占仅减少可用量，增加预占量；取消恢复可用量；发料减少源库存现存量及预占量，线边库存现存量及可用量同步增加。
- 预占、释放、核销保留独立审计事件；实际发料生成 ISSUE_OUT/ISSUE_IN 配对流水，关联领料单，不伪造收货记录或生产消耗。
- 需求号全局唯一并校验内容，重复请求返回原单；预占、发料、取消均按单据状态幂等，不允许重复扣账。取消重试必须保留原原因。
- 双仓权限与双仓固定顺序锁，禁止不合格、过期、非正式库位及非原料到线边用途的操作。取消允许停用仓释放既有预占。
- 预占变化使原盘点快照失效，即使取消后数量恢复也需重新盘点；普通移库只能动用未预占量。

## 验收标准

验证正常预占/取消/发料、重复及冲突请求、并发超预占、双仓权限、失效库存、盘点/移库兼容、流水失败整笔回滚、前端写入确认与错误处理。隔离环境浏览器验收，日常数据库不自动升级。PR 基于库存盘点 PR，依赖按顺序审批合并。

## 接口与权限

- 模拟需求：POST /api/local/mes-demands；GET /api/local/mes-demands/capabilities。仅 local/test 管理员。
- GET /api/v1/wms/issues 按 warehouseId、targetWarehouseId 双仓查询，page 从 0 开始；GET /{id} 与 GET /{id}/events 查看单据和预占审计。
- POST /{id}/reserve（balanceId、targetLocationId）、/{id}/cancel（reason）、/{id}/confirm。
- 权限：wms:issue:read/reserve/cancel/confirm，非管理员需要源仓与目标仓两个 wms:warehouse:<id>；页面还需 warehouse:read，选择库存需 wms:inventory:read。既有账号不自动增加权限。
- 当前模拟 MES 通过需求接收响应与单据查询获得状态；尚未接入真实 MES 或发料结果异步反馈，不复用收货专用 Outbox。

# 生产冲正与成品出入库

## 本轮范围与顺序

用户授权依次完成生产冲正、成品入库、销售出库；每项单独提交依赖 PR，保留统一审批。沿用最小会话认证、双仓/单仓数据范围、事务库存流水和 Outbox。仅本地模拟 MES/QMS/ERP，不连接真实平台，不升级日常数据库。

## 1. 生产冲正

首版整笔冲正一条实际消耗或一张已确认生产退料。申请记录原单、原因、外部纠错参考号，由另一人批准或驳回；申请人可撤销待审。审批禁止自审、重复和并发重复过账。已批准原记录不可再次冲正，不删除或覆盖原流水。

消耗冲正恢复原线边库存和工单归属额度；退料冲正从原退回库位扣除数量，恢复原线边归属。退回库存自原入账后发生任何后续物理流水，或存在占用/库存不足时拒绝冲正；不能回撤已被后续业务使用的库存。冲正适用于已核对实物和 MES 纠错结果的记账错误，不是任意补库存入口。不合格退料冲正需核对原质量记录与实物归属，禁止把正常质量处置误当纠错。

审批与反向流水、净消耗/净退料计数及 MES 补偿事件同事务，事件包含原事件类型和原业务记录号。原始 MES 请求重发仍返回原记录，不重新扣账。

## 2. 成品入库

模拟 MES 提供唯一完工入库需求号、工单、成品物料、批次、数量及日期信息。仓管确认整单实物进入成品仓待检位，模拟 QMS 对整批作合格/不合格判定；合格批次确认上架至同仓正式库位后才可用，不合格留隔离。保留工单与入库单到批次库存的追溯，不能把成品伪装成供应商采购收货。

首版单物料单批次整单收货、整批判定、整批上架；禁止重复入账、超量和跨仓库位。成品没有采购供应商，扩展库存来源表达且保持既有原料维度兼容。MES 完工需求是产出依据，WMS 不根据原料消耗推算产量，不实现 BOM 或生产报工计算。

## 3. 销售出库

模拟 ERP 提供唯一需求号、销售单参考、客户参考、成品物料、数量和仓库。整单选择一条合格未过期成品库存预占；拣货核对批次数量，另一人复核后，仓管确认实际出库才扣实存。复核不通过退回重新拣货，待出库单可带原因取消并释放预占；已出库不可取消。消息反馈记录实际出库结果，不含运输签收、财务及销售退货。

每项交付前均执行专项与必要回归、前端验证、内置浏览器验收，扩展库存对账。所有迁移只追加；升级前备份，保持旧应用停止写入，失败恢复匹配备份。

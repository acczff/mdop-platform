| 内置浏览器正常流程 | 新建供应商/客户/单位/物料/组织、供应商改名停用及审计、单组织禁止重复创建；物料业务引用后锁定单位/策略但允许改名，原到货明细仍显示旧名称；只读账号无维护/审计入口 |

浏览器使用独立 8082 后端、5174 前端和新建的隔离 MySQL/RabbitMQ，未替换日常数据库。客户销售单端到端校验随 SAL 工作包实施，生产地点 MD-05 留 R2；库存查询等库存作业仍展示当前物料名称，不宣称全部历史表已增加快照。远端 CI 结果以本 PR 对应提交检查为准，本地记录不能替代远端通过证明。

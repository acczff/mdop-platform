# I9 库存查询与追溯

> 交付更新（2026-10-07）：相关实现已进入 main，WMS 公共流程已完成有限验收，见 [当前验收与合并记录](WMS公共流程验收清单.md)。本文各次测试数量、迁移数量及环境记录保留其当时含义，不代表当前总量或生产部署状态。

本阶段首个切片提供独立只读库存页面 `/inventory`，不改变库存记账规则，不增加数据库迁移。

## 查询与追溯

- 按仓库、物料编码/名称、供应商批次精确匹配、质量状态筛选；默认隐藏零库存，可勾选查看历史维度。
- 每页 20 条，服务端最多 100 条，按库存 ID 倒序稳定分页。
- 流水显示原收货单、ERP 到货通知、采购单、变动前/变动/变动后数量、操作人和时间；冲正关联原流水，退货关联 RT 申请编号。
- 数量由数据库 DECIMAL 转为字符串传输，前端原样显示六位小数。不同物料和单位不做混合合计。
- 库存维度显示当前主数据名称；流水接口同时保留来源到货明细的物料和单位快照。原始流水不覆盖。

## 接口及权限

- `GET /api/v1/wms/stock`：必填 warehouseId；可选 keyword、batch、quality、locationId、includeZero、page、size。
- 此接口及流水分页从 page=0 开始；size 默认 20，最大 100。仓库主数据既有接口仍从 page=1 开始。
- `GET /api/v1/wms/stock/{id}`：单个库存维度。
- `GET /api/v1/wms/stock/{id}/transactions`：该维度的历史流水，最新在前。
- 需要 `ROLE_ADMIN` 或 `wms:inventory:read`；非管理员还必须有对应 `wms:warehouse:<id>`。列表、详情和流水都校验仓库权限。
- 默认不自动扩大现有 receiver/reviewer 权限；需要查询权限时，在项目本地操作员配置中显式增加 `wms:inventory:read`，保留仓库范围。

## 回归范围

后端覆盖六位小数精度、多次收货来源追溯、分页顺序和空页、质检分流与零库存筛选、字面量关键词、功能权限和跨仓访问、匿名请求、非法查询参数。前端覆盖分页保留已提交筛选、权限仓库展示、退货来源呈现，以及失败后清空旧结果。

后续工作为库存移库与盘点方案，以及领料出库的可用量预占和释放；本次不宣称这些业务已经实现。

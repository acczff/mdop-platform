# 销售数量履约：S1—S3

执行范围为 [SAL-01—04](03-销售.md)，基于采购 PR #37 的 `15687fa`，分支 `acczff/erp-sales-fulfillment`。本页记录实现约定与操作，验证证据见[版本记录](../project/status.md)；候选交付不代表已合并主干或完成 R1 联合验收。

## 1. 单据与职责

ERP 客户订单为独立 sales 模块，状态为 DRAFT → SUBMITTED → APPROVED → FULFILLING → CLOSED；驳回为 REJECTED，可编辑后重提。单客户、单成品仓、多物料，基本单位、六位小数，同物料合并。客户编号和名称、仓名及物料单位保留快照，批准后不改客户、仓库或数量。销售作业与审批分角色，创建/编辑/提交人不能审核自己经办的订单。

草稿保存后若物料基本单位变化，提交和审批均拒绝，原数量、单位快照、版本与审计不变。刷新目录后，由作业员在草稿或驳回状态明确编辑并核对新单位数量，再重新提交；待审核单须先驳回。不将原来的“10 件”静默解释为“10 箱”。

每份发货安排对应一个订单行，状态 PENDING → DELIVERED 或 WITHDRAWN，记录数量、计划日期、来源 ID、WMS 执行 ID 及送达失败原因。安排占用授权，不预占库存；库存参考不是可发承诺。100 件可以安排 60+40，但同一安排对应的 WMS 单仍是单库存、单批次整单执行。缺货由 WMS 拒绝预占，订单保留未发量。

## 2. 跨模块和事务

ERP 通过 common 的 SalesShippingPort，由 integration 适配到 WMS 正式来源服务。WMS 使用 MDOP_SALES 来源，按安排行唯一映射和载荷摘要防止重复或异载荷建单；保留旧模拟入口，正式来源不能被模拟入口冒用。ERP 不访问 WMS 表，不另外维护库存数量账。

同进程同库契约原子送达/撤回，仓库 → ERP 单据/WMS 执行单 → 库存的锁序沿用现有机制。未知结果保留安排额度和原请求键。所有安排实际撤回、预占释放且没有实际出库后，才可取消 ERP 订单。WMS 已独立取消的单据可以在 ERP 确认撤回，原取消原因不覆盖；已经出库不能取消。

页面刷新同时重读主数据目录。原请求重试返回 401/403 时保留凭据，恢复登录与原操作权限后核对；无原写入/审批权限或仓库范围时不能重试。凭据无法读取或清理则停止新操作，写入后的迟到读取不能恢复旧单据列表。

正式销售直接读取 WMS 已提交执行及库存流水事实，不依赖模拟消息累计；正式单实际出库不投递给旧模拟 ERP 消费者。模拟销售仍沿用原 Outbox。未来跨库时另建可靠投递协议，不把同库读取描述为分布式交付。

## 3. 核对与结案

已发量仅取实际出库事实，预占/拣货/复核不计已发。未发 = 订单授权 - 实际已发。来源映射、物料/单位/数量及出库流水必须一致，PENDING、未出库、未确认撤回或来源矛盾均阻止结案。所有行收口时保存不可变结案快照、摘要、操作者、时间及原因。后续读取重新核对来源，差异提示待核对而不改写原快照。

## 4. 验收清单

| 编号 | 主流程与异常 |
|---|---|
| S1 | 建单、编辑、驳回重提、异人审批；无效/停用客户或物料、单位变化、自审、越仓、旧版本及重复请求 |
| S2 | 100 按 60+40 安排；并发超量阻断；重复送达一份执行单；失败保留额度、原键重试；授权快照与正式来源隔离 |
| S3 | 预占→拣货→异人复核→出库，累计实际发出后结案；缺货、冻结、过期、复核驳回、重复出库、并发撤回与发货、已发不可取消 |
| UI | 只读入口、迟到响应、切单/切仓、未知写入结果凭据持久化、刷新失败、来源导航、桌面/窄屏 |
| 交付 | 空库/已有隔离库迁移、相关回归、浏览器演练、CI 和文档；不升级日常库，不合并待审批 PR |

本轮不含客户退货、应收收款、价格折扣、自动分仓配库、波次策略、签收运输、短交结案或动态审批。销售闭环完成后进入 R1 采购/销售联合验收；不因此直接开始 R2/R3。

## 5. 操作演练

1. 系统管理员分配销售作业员、销售审批员、仓库作业员、仓库业务审批员及目标成品仓范围，作业与对应审批使用不同账号。销售账号需要查看 WMS 时另授业务只读角色；不能因系统管理员身份自动操作业务。
2. 在“销售订单”选择成品仓，选择启用客户、物料、基本单位数量与交付日期，保存草稿、提交审核。另一销售审批员核对后批准；驳回可改草稿重新提交，批准后不可修改订单数量。
3. 按订单行安排第一批 60、第二批 40；每次送达前核对数量和日期。送达失败仍占额度，详情保留原因。网络未知时页面保留原键和原载荷，重新打开仍提供“原样重试”，不要新建替代单。
4. 从“查看 WMS 出库”进入准确执行单。仓库作业员选择同物料合格自产库存，查看可用量参考并确认预占；缺货、冻结、过期由 WMS 阻断。库存参考沿用 WMS 选择库存页，不在 ERP 重建分配功能。
5. 作业员填写实际批次与整单拣货量，另一仓库审批员复核；退回后重新拣货。实际出库前库存现有量不减少，ERP 已发量不增加。确认实际出库后该执行单不可取消。
6. 回销售订单“核对最新进度”：第一批出库后已发 60、未发 40，不能结案；第二批出库后已发 100、未发 0，流水一致才可“履约结案”。记录原因并保存数量快照，财务金额仍未建立。
7. 未实际发出的安排可以撤回；已预占时同步取消 WMS 并释放预占。仓库先行取消时，销售端仍需确认撤回才释放安排额度。所有安排安全撤回后才能取消订单；部分已发保留未发责任，不支持短交结案。

演练的成品供应可用明确标记的模拟 MES 完工与模拟 QMS 判定，正式客户订单和发货安排必须从上述销售模块创建。自动化证据与隔离库记录见[版本记录](../project/status.md)。

# 02 采购执行规格

R1 建设数量履约，PUR-06 金额衔接随 R3。遵循[共同执行约定](README.md)，已有[采购切片](../project/采购履约实施切片.md)补充数量核对和 WMS 场景。本模块从零建设，现有模拟 ERP 不算已实现采购功能。

本分支新增 PUR-01/02 的[采购 P1 实现与验收](采购P1实现与验收.md)；提交及验证状态以[版本记录](../project/status.md)为准。其余编号仍为执行规格。

PUR-03 的分批到货与 WMS 衔接见[采购 P2 实现与验收](采购P2实现与验收.md)。PUR-04/05 履约归集与结案及 PUR-06 金额衔接尚未完成。

## 1. 最小闭环与角色

手工采购需求 → 审核 → 转采购订单 → 订单审核 → 分批到货安排 → WMS 收货/质量处置 → 履约结案；R2 可接收物料需求作为需求来源，R3 关联应付依据。采购员建单，异人审核，仓管执行，财务人员处理金额；采购员不直接改库存。

## 2. 基本功能工作包

| 编号 | 功能与最小信息 | 页面/动作 | 关键依赖 |
|---|---|---|---|
| PUR-01 | 需求编号、来源、申请人、用途、收货仓、物料行/数量、需要日期、状态/版本 | 需求列表/详情、编辑、提交、审核/驳回、撤销；手工需求先行 | MD 有效引用；R2 来源携带生产订单和需求行身份 |
| PUR-02 | 采购订单编号、供应商、仓库、需求行关联、物料/单位快照、数量、约定到货日期、版本与审计 | 审核后需求整行转单、订单编辑/提交/审批/取消、原单查询 | 同一有效需求行只占用一次；供应商由采购员选择，不自动寻源 |
| PUR-03 | 到货安排号、采购订单行、安排数量、来源 ID、WMS 通知映射及投递状态 | 分批安排、查询送达结果、受控撤回 | 累计有效安排不超授权；结果未知/撤回未确认仍占额度 |
| PUR-04 | 逐行收货、冲正、待检、合格待上架、已上架、不合格未退供、实际退供事实 | 履约详情、进入 WMS 相关单、差异原因、结果重查 | 通过契约读取/接收事实；独立映射行号，不按采购单号/物料猜关联 |
| PUR-05 | 业务结案与异常处理：剩余责任、阻断原因、退供交接及结案快照 | 未完成清单、查证/授权重试、符合条件时结案 | 下游事实无未决差异；不合格需真实退供后才能按初版口径处置完结 |
| PUR-06 | R3 采购金额依据、与收货/退供行的关联、应付及反向记录引用 | 金额依据确认、查看应付/核销，不由采购员登记付款 | FIN-01/02；不得把数量订单默认金额 0 或自动当应付 |

## 3. 状态与关键规则

需求：草稿 → 待审 → 已批准 → 已转单；驳回可改，未转单且无占用可撤销。订单：草稿 → 待审 → 已批准 → 履约中 → 已结案；未执行且所有安排撤回确认后可取消。审核后不改供应商、仓库和授权数量；不是动态多级审批。

首版一份同仓需求选择一个供应商生成一张订单，多物料行、同物料在需求中合并，需求行与订单行一一关联；整行转单，不做跨需求汇单或按供应商拆单。订单取消后释放需求占用须核对无实物事实、下游均撤回、消息无未决结果；不能因订单列表显示取消就直接再转一份。

收货冲正减少净收货；实际退供是处置结果，不自动减少已履约的收货授权或恢复补货额度。补货另建关联原单需求/订单，仍需审核。待检/待上架/不合格待处置相互排斥，已上架为累计事实，不因后续领用减少。部分未到货保持未结案，不设置强制结案或短交核销。

## 4. 同编号验收与基本异常

| 编号 | 验收场景与结果 |
|---|---|
| PUR-01 | 100 件需求审核后锁定；驳回才可改；生产来源重复导入不多一张需求，取消不能抹掉已经转单的责任 |
| PUR-02 | 两个并发转单仅占用一次同需求行；需求未批准/越仓/自审拒绝；订单取消失败或未知时不可释放需求再转单 |
| PUR-03 | 100 件安排 60+40 成功，再安排 1 件拒绝；重复投递只有一份 WMS 通知；撤回与收货竞争不会同时生效 |
| PUR-04 | 未进入下游的收货 20 件冲正后数量一致；重复、乱序反馈不能恢复已冲正事实；待检不计成合格 |
| PUR-05 | 100 件中 80 合格上架、20 不合格，退供确认前阻断结案，确认后显示含退供结案；少到时明确剩余，不生成伪收货 |
| PUR-06 | 同一金额依据重复处理不多生成应付；退供关联原金额依据，可追溯反向记录；应付未建立/付款未结清不阻碍显示真实实物履约状态 |

全部写入适用 C-01—C-06；查证/重放需要操作权限，并保留原因，不能从异常页面直接改余额。

## 5. 工厂差异与停止条件

| 差异 | 当前初版 | 实际工厂明确后再做 |
|---|---|---|
| 采购发起 | 手工或 R2 需求、固定审批 | 多级申请、预算/合同控制、自动补货 |
| 供应商选择 | 人工指定 | 询比价、配额、供应商门户、委外采购 |
| 数量与交期 | 不超授权，分批安排，少到保留责任 | 超收容差、最小批量、交期变更和短交结案 |
| 质量与退供 | 复用已确认 WMS/QMS 演练规则 | 抽检复检、让步、退换货联动、赔偿 |
| 金额 | FIN 确定后保存明确依据 | 含税/未税、运费分摊、付款条件和价格调整 |

R1 完成 PUR-01—05 及既有采购验收即可收口；R3 完成 PUR-06。不能把询价、财务付款或所有退换货策略追加为 R1 必做项，也不能永久省略已排入 R3 的应付衔接。

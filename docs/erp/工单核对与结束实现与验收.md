# 工单核对与受控结束（MFG-06）

范围依据：[生产与物料计划](05-生产与物料计划.md)。本轮补齐生产数量闭环的结束动作，不包含成本结算、短产强制结案、返工报废、重新打开工单或日常部署。

## 结束条件

生产订单详情提供“结束核对”：逐项展示材料理论用量、实际净消耗、退料、线边余料、关联采购、完工报告和成品上架。核对从来源事实重算，不以当前成品库存余额代表历史入库量。

- 工单已经批准；批准完工量等于授权量，无待复核报告；每份批准报告对应唯一、数量一致且已合格上架的成品入库单。
- 材料计划存在，每种 BOM 组件有实际消耗依据；领料已取消或实际发出，线边归属余量、待退料、待审冲正均为零；净消耗/退料与原始记录及反向记录一致。
- 关联采购需求已取消，或其有效订单已数量结案且结案事实仍一致；仅实收完成、存在未审需求或未决采购，不视为供给收尾。
- 材料实际净消耗与理论用量不一致时，必须单独填写差异说明，由生产审核员连同结束依据确认；不自动补扣材料、不把完工量推算为消耗。

沿用生产审核权限和仓库范围，需求/工单经办人、实际完工登记人不能审核结束自己的业务。结束时重新锁定相关仓库和制造保护锁，核对页面事实摘要与工单版本；变化即拒绝并要求刷新。完成后保存不可变快照、差异说明、操作者和时间，工单标为已完成，原需求占用保留，不能重复转单。成本始终显示“未建立成本结算依据”。

已结束工单不接受新增材料计划、领料、消耗/退料、冲正及完工授权；已成功请求原样重试仍可查证。结束后查询持续对照原快照，有差异显示待核对，绝不重写结束历史。

## 接口、锁与迁移

- `GET /api/v1/manufacturing/orders/{id}/closure`：生产读取权限及成品仓、供料仓、线边仓范围。返回当前核对、`factHash`、结束记录、`closureMatches` 和成本边界。
- `POST` 同一路径：生产审核权限，提交请求键、工单版本、读取的事实摘要、结束依据及材料差异说明；禁止工单经办人和有效完工登记人自审。
- 写入按仓库 ID 排序锁定全部关联仓库，再取得制造保护锁；若关联仓库变化则拒绝刷新。制造计划、采购/库存操作继续使用原仓库锁序；冲正创建与审核复用制造保护锁，和结束竞争不能同时成功。
- 迁移 `202610120001` 扩展工单 `COMPLETED` 状态，新增 `mfg_order_closure` 保存原始核对。保留有效需求引用，不释放数量另建工单。迁移不自动结束旧单、不生成成本历史。
- 制造只通过 `ProductionMaterialPort`、`ProductionCompletionPort`、`ProductionPurchasePort` 读取跨模块事实。核对来源、净数量、领退耗/反向流水及成品上架流水；不要求已售出成品仍在原库。结束后允许既有成品合法销售/移库，不认定为生产历史变化。

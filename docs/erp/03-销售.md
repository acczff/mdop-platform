# 03 销售执行规格

R1 建订单到实际出库，R3 补基础客户退货及金额衔接。遵循[共同执行约定](README.md)。已有 WMS SalesOrder 是出库执行单，不替代 ERP 客户订单。

候选实现更新（2026-10-09）：本分支新增独立 ERP 销售模块，覆盖 SAL-01—04，操作、实际状态与验收边界见 [S1—S3 实现与验收](销售实现与验收.md)。下文是总体规格，SAL-05/06 仍未实施。

## 1. 最小闭环与角色

客户订单 → 审核 → 按行分批发货安排 → WMS 预占/拣货/异人复核/实际出库 → 反馈及出库履约结案；R3 关联应收和受控客户退货。销售员建单、审核员审核、仓管执行、财务处理往来；现有“采购来源原料不能当自产成品销售”的 WMS 边界保持不变。

## 2. 基本功能工作包

| 编号 | 功能与最小信息 | 页面/动作 | 依赖 |
|---|---|---|---|
| SAL-01 | 客户订单号、客户、出库仓、交货日期、物料行及数量/单位快照、版本和状态 | 订单列表/详情、创建/编辑、提交、审核/驳回 | MD 客户/物料/仓库；客户外部参考号可选，不作为内部唯一 ID |
| SAL-02 | 发货安排号、订单行、数量、WMS 执行单映射、安排/投递状态 | 分批安排、查看库存参考与执行进度、重查 | 安排量不超剩余授权；库存参考不是预占成功承诺 |
| SAL-03 | 预占、拣货、复核、实际出库事实及累计已发/未发 | 订单履约详情、进入 WMS 执行、结果核对及结案 | 保留 WMS 单执行单整单/单条库存/单批次限制；一张 ERP 订单可产生多张执行单 |
| SAL-04 | 驳回、未执行取消、释放安排额度/预占、阻断原因与审计 | 安全撤回/取消、查看未完成责任 | 对方确认取消后才释放；已出库不可普通取消 |
| SAL-05 | R3 客户退货：原出库单/行、数量、原因、申请/审核、实际接收、质量处置、金额反向引用 | 退货申请/审核/跟踪；仓管执行实际接收；查看隔离及处置结果 | INV-04、FIN 反向处理；实际接收前不加库存，不自动退款 |
| SAL-06 | R3 销售金额依据和应收来源映射 | 金额依据确认、往来查看及与原交货事实关联 | FIN-01/02，物理发出与应收确认分别记录 |

## 3. 状态和数据约束

订单：草稿 → 待审 → 已批准 → 履约中 → 出库履约已结案；符合未执行条件时可取消。每张发货安排有待发送/待确认/已受理/已取消等衔接状态，实际作业状态由 WMS 提供；不把消息失败改成订单已取消。

已发量只累计实际出库，预占/拣货/复核都不增加已发量。未发量 = 订单量 - 实际已发量；结果未知的安排继续占用安排额度。所有行实际出库达授权量、安排无未决结果、对账一致才可结束出库履约；财务未结额另行展示。

首版退货只处理本系统已有实际销售出库依据，不收无来源退货。退货申请及在途退货占用可退额度，实际接收转为已退事实；取消未接收申请才释放额度。累计有效申请/接收不得超过原出库可退数量。收到货后先隔离，人工/模拟 QMS 结果明确标识；合格整笔转回可用，不合格保留隔离。首版每张退货执行单单原出库行、单批次、整笔接收/判定，可多张申请，暂不做无来源退货、部分判定、换货及报废处置。

原订单已发记录不因退货改写；另列已退数量，不自动恢复原订单发货额度。补发需要新的关联订单及审批。已收款退货可能形成待退款责任，由 FIN 明确处理，不能简单把已收款记录删除。

## 4. 同编号验收与基本异常

| 编号 | 验收场景与结果 |
|---|---|
| SAL-01 | 客户停用、物料无效、越仓或自审拒绝；订单批准后原数量不能直接改；历史客户改名不改旧单快照 |
| SAL-02 | 100 件分 60+40 安排，重复/并发不超过 100；缺货时显示未执行，不伪造预占；一个安排只对应一次有效 WMS 建单 |
| SAL-03 | 两张执行单分别出库后已发 100；重复出库反馈不累加；复核退回及冻结/过期拒绝不减少实存 |
| SAL-04 | 已预占未发单安全取消后只释放一次；取消与发出竞争不可双成功；有实物发出后整张 ERP 订单不能普通取消 |
| SAL-05 | 原发出 10，申请退 4 后剩余可退 6；并发再申请 7 拒绝；确认收到 4 才入隔离库存，重复确认不重复入账；不合格继续隔离，不自动恢复可用 |
| SAL-06 | 重复应收依据只记一次；退货关联原发出/金额行，已收与未收分别处理；退货不覆盖原收入/收款记录，不把程序登记当银行退款 |

适用 C-01—C-06；订单和退货的只读用户不能通过详情接口执行作业，不能仅靠导航隐藏。

## 5. 工厂差异与停止条件

| 差异 | 当前初版 | 实际工厂明确后再做 |
|---|---|---|
| 客户订单 | 人工建单、单客户单仓 | EDI、电商、客户门户、集团跨厂订单 |
| 交货 | 人工分批安排、WMS 现有执行能力 | 多仓自动分配、整箱规则、承诺交期/ATP、运输签收 |
| 商务 | R3 明确的金额依据 | 价格表、阶梯折扣、信用额度、合同/税务条件 |
| 售后 | 原销售关联退货、接收隔离及结果处理 | 换货、保修、无单退货、赔偿及自动退款 |

R1 完成 SAL-01—04；R3 完成 SAL-05—06 才满足总体销售范围。客户退货只扩展必要库存与金额反向链，不顺带建设售后服务平台。

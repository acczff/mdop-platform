# 07 查询与控制执行规格

每轮随业务交付，R4 联合核验。遵循[共同执行约定](README.md)。它是各业务页面和服务必须具备的能力，不是另建工作流、报表或异常处理平台。

## 1. 现有基础与差距

复用现有 Session/CSRF、账号版本失效、固定角色、仓库范围、业务审计和 Inbox/Outbox。当前角色目录没有完整 ERP 采购、销售、生产和财务职责；当前模拟接口权限也不是正式 ERP 消息重放授权。扩展只做到当轮需要，保持旧角色和历史账号兼容。

## 2. 基本功能工作包

| 编号 | 必做功能 | 页面/操作 | 服务端责任 |
|---|---|---|---|
| CTL-01 | 角色及动作权限：作业、审核、财务、消息处理与只读分离，按仓/对象控制访问 | 复用用户授权页，按业务展示入口和动作 | 逐请求校验；跨仓对象校验涉及的范围；系统管理员无默认业务全权，不因换角色允许自审 |
| CTL-02 | 单据全链路和过程查询：来源、版本、相关单、当前状态、计划/实际/剩余、历史操作者 | 各订单详情的关联页签，条件查询和分页、详情跳转 | 用稳定关联而非模糊单号；返回可见对象，不能通过关联页泄露财务或越仓数据 |
| CTL-03 | 审批及业务动作审计：谁在何时依据何版本做了什么、原因、结果及关联事件 | 原单历史、审批原因、冲正关联 | 成功事实与审计同事务；失败拒绝按日志策略记录且不生成假业务成功记录；敏感凭据不入日志 |
| CTL-04 | 异常和消息查询：已发送、已受理、业务生效分别展示；待核对及明确原因 | 各单失败/待处理区，原请求查证，有权限重试或重放 | 区分可原样重试、需更新状态、需人工依据和暂不支持；无权限者不能重放或改来源 |
| CTL-05 | 业务对账：订单→安排→执行→反向事实，生产归属，往来/金额核对及差异 | 当轮订单内对账，必要的跨单差异列表 | 明确数据截至时间/未处理事件；不把短暂未消费直接判成永久丢单；差异阻止相关结案 |
| CTL-06 | 安全交互与有限摘要：剩余任务、超期提示、待处理、已完结/已结清分别显示 | 有范围的列表筛选、详情统计、操作后刷新和错误反馈 | 统计与列表同权限、同口径；迟到请求不可覆盖新单，结果未知时锁住会造成重复的动作 |

## 3. 可执行初版规则

所有入口复用当前管理端和账号系统。固定角色随对应模块添加，首版不开发自定义角色编辑器、组织继承、动态菜单平台或审批流程设计器。权限定义要落实到动作与对象：例如可读订单不自动可读金额，可重试采购事件不自动可调用模拟 MES 输入。

查询最少支持业务编号、日期范围、状态、仓库和相关往来方/来源条件，按本模块实际字段实现；默认分页和最大条数必须明确，不先提供无权限限制的全量下载。消息内容查询应最小化和脱敏，不能把 Cookie、密码或原始认证信息展示在审计。

采用原业务单记录异常原因、发生时间、关联事件与处理记录；跨单列表从这些事实形成，不提前建立通用异常工单模型。操作只调用领域已有的审核、撤销、冲正、重放等合法动作，不提供“修正余额”“强制完成”通用按钮。

差异核对同时保留生产者事实和消费者处理状态。缺来源时等待查证或人工关联依据，不能从不同单据猜一条匹配；人工处理需要合法业务动作和原因，不能在处理台改原事件载荷冒充相同请求。

列表刷新失败即失效旧操作区域；写请求结果不明时保留原键/载荷并阻止换内容重发。状态冲突先读最新事实，权限失效退出或拒绝；超期提示不是自动取消/违约判断。

## 4. 同编号验收与基本异常

| 编号 | 验收场景与结果 |
|---|---|
| CTL-01 | 只读用户直接调写接口、越仓查详情、申请人换审核角色后自审均被拒绝；授权变更使旧会话失效；采购查看不越权泄露财务 |
| CTL-02 | 一张订单两次执行和一次反向可逐行追到原记录；相同外部编号不同来源不混单；无权限关联不泄露对象内容 |
| CTL-03 | 审批与审计一起成功或一起回滚；冲正原记录可读；历史查不到时不开放需依赖该证据的敏感操作；日志不包含凭据 |
| CTL-04 | 同一失败事件只能原样重放；已消费结果不再重复过账；未知状态、明确失败和业务成功分别显示，无权者重放失败 |
| CTL-05 | 明细汇总与结案条件一致；未决反馈显示待核对而非完成；真实差异定位到单/行并阻止结案，不自动改账消差 |
| CTL-06 | 快速切单/切仓后旧响应不覆盖新结果；写成功后刷新失败不提示重新创建；不同权限用户看到的数量与金额统计一致地受限 |

适用 C-01—C-06；现有前端迟到响应和不确定写入保护应继续回归，不因抽公共组件而弱化。

## 5. 工厂差异与停止条件

| 差异 | 当前初版 | 取得实际依据后再做 |
|---|---|---|
| 组织权限 | 单组织、固定角色、明确仓库范围 | 多组织、多租户、部门继承、临时授权委托 |
| 审批 | 固定职责和异人校验 | 金额分级、多级会签、代理、工作流引擎 |
| 通知/指标 | 页面待处理、事实统计、超期提示 | 企业消息平台、SLA 告警、经营 BI 和自定义报表 |
| 异常协作 | 原单原因/历史、合法动作 | 跨部门工单、责任赔偿、自动补偿规则平台 |

停止条件：当轮业务能查来源、看进度、判权限、定位异常、执行合法恢复并对账。没有新增独立“平台模块”也可完成本部分；不能只交付一个空仪表盘代替控制能力。

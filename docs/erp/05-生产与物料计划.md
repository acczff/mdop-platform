# 05 生产与物料计划执行规格

适用 R2。遵循[共同执行约定](README.md)。目标是生产需求、材料供给与实际产出有依据，不建设完整 MES 或高级排程。

## 1. 最小闭环与责任

销售/手工生产需求 → 生产订单及固定 BOM → 材料需求/缺料 → 采购需求或库存领用 → 线边消耗/余料退回 → 完工结果 → 成品待检/上架 → 工单结束。

计划员建需求/订单与确认需求计算，审核员批准生产授权，仓管执行领退料及成品入库。生产结果由受控人工入口或明确标识的模拟 MES 提供；不允许无来源人员直接填库存。QMS 沿用当前模拟判定，不把物料消耗自动换算成已完工数量。

## 2. 基本功能工作包

| 编号 | 功能与最小信息 | 页面/动作 | 约束 |
|---|---|---|---|
| MFG-01 | BOM：产品、版本、基准产量、组件/基本单位及用量、状态、生效记录 | BOM 列表、草稿编辑、发布/停用、版本历史 | 首版单层离散装配，组件按已有物料供给；不用多层自动工单递归、联副产品或替代料 |
| MFG-02 | 生产需求与订单：来源销售行/手工依据、产品、计划量、生产地点、目标成品仓、日期、BOM 版本快照、审核/版本 | 需求转生产订单、审核/驳回、订单详情/取消 | 批准后冻结 BOM 和授权产量；同来源分配不超有效需求，不能重复建工单 |
| MFG-03 | 按 BOM 展开理论材料需求、当前可用参考、已关联供给与缺口 | 需求计算结果及版本、人工确认采购建议、转采购需求 | 计算不预占、不自动采购；确认转单时核对版本和已转量，避免旧快照重复建议 |
| MFG-04 | 关联 WMS 领料需求、预占、发至线边、实际消耗与余料退回 | 工单材料页、生成受控领料需求、查看执行及差异 | 用工单授权和材料需求行关联；库存与线边归属仍由 WMS 保护 |
| MFG-05 | 完工事实：工单、报告号、产品、批次、日期、本次完工量、结果来源、操作者 | 人工完工登记/复核或模拟 MES 接收、生成成品入库需求、查询待检/入库结果 | 完工是独立事实，累计不超工单授权；完工不能直接变可用库存 |
| MFG-06 | 工单进度、材料/成品差异、待处理与受控结束 | 看板/详情、未完原因、结束/取消审计 | 实物、生产授权及成本结算状态分开；有未决供给、线边余料或质量待处理时不得伪造全部完成 |

## 3. 初版规则与数据约束

BOM：草稿 → 已发布 → 停用；已被工单引用的版本不可原地改。新版本不回写老工单。校验基准产量/用量为正、单位明确、组件无重复和直接/间接循环引用；单层初版不自动展开组件自己的 BOM。

生产订单：草稿 → 待审 → 已批准 → 执行中 → 已完成；只有无领料/消耗/完工、无有效供给占用且下游撤回确认时才允许取消。批准后需要变更产品、版本或数量时，当前初版拒绝直接覆盖；未执行可安全取消后重建，部分执行保留待处理。

理论需求 = 计划产量 ÷ BOM 基准产量 × 组件用量。初版无损耗率和替代料，使用十进制精确运算；需求结果超过六位小数时向上取至六位，页面显示计算依据和舍入差，避免静默少算。该规则是本项目演示选择；工厂若要求整数件、包装倍数或专用精度，需明确对应单位规则后调整，不能据此宣称已经支持所有计量场景。

缺料是计划参考，不承诺库存已分配。初版不汇总全厂在途、不做时间桶优化：展示理论需求、该需求已关联采购/领料、当前可用参考与仍需处理量。可用参考来自同一查询快照；真正预占由 WMS 再校验。其他工单争抢库存导致预占失败时刷新缺口，不继续按旧数发料。

领料按已授权材料需求分次发起；已发到线边不等于已消耗，退回和反向事实单独累计，复用现有生产归属约束。首版不默许超领或以负消耗补库存。实际材料消耗与理论用量存在差异时保留差异原因，不为了匹配 BOM 自动扣料。

每条完工结果有稳定报告号，人工结果需独立复核后授权下游。原报告重复返回原结果，同号不同内容冲突；报告量、成品入库需求、实收、质量与上架分别核对。完工不合格保持隔离和待处理，首版不自动返工/报废。生产业务完成要求产量达到授权且原料/成品处置无未解释差异，财务成本是否结算另列。

## 4. 同编号验收与基本异常

| 编号 | 验收场景与结果 |
|---|---|
| MFG-01 | 产品每件需材料 2，发布版本 V1；V2 用量变更后老工单仍使用 V1；用量为零、循环、自引用、单位不明拒绝 |
| MFG-02 | 销售需求 10 转生产 10，重复转单不生成第二份授权；自审/越仓拒绝；工单已领料后不能普通取消 |
| MFG-03 | 生产 10 需料 20，可用参考 4，未关联其他供给时缺口显示 16；两次确认采购建议不重复建 16；单件理论需求 1/3 按初版规则显示 0.333334 及舍入依据；快照过期需刷新，不把计算当预占 |
| MFG-04 | 20 发到线边、实际消耗 19、余料退回 1，线边归属归零且材料事实可追溯；原料差异与成品产量分别记录；冲正重放不多发料 |
| MFG-05 | 完工报告 6+4，分别形成有来源成品入库需求；累计第 11 件拒绝；重复结果不多建入库；缺生产日期/批次依据时拒绝，不生成虚假日期 |
| MFG-06 | 材料已清但仍有成品待检时显示未完成；不合格未处置明确阻断；完成不表示成本结清，消息未对上时保留待核对 |

适用 C-01—C-06；需求、已领、消耗、退回、报告、成品入库和可用量应能从各自事实重算。

## 5. 工厂差异与停止条件

| 差异 | 当前初版 | 取得实际资料后再做 |
|---|---|---|
| 制造模式 | 单层离散装配演示 | 流程/配方、联副产品、委外、返工、装拆转换 |
| 材料计算 | 固定版本、零损耗、基础缺料参考 | 多层 MRP、批量/提前期、安全库存、替代料、损耗率 |
| 计划执行 | 人工计划/复核，固定数量授权 | 产能日历、设备负荷、APS 优化、自动排程 |
| 现场事实 | 人工或模拟结果、工单归属 | 工序报工、计件、工时采集、设备/IoT 联动 |

停止条件：六项闭环和异常成立，可从销售需求追到材料和成品事实。适用性仅为初版离散模型；不同制造模式不通过增加几个自由字段冒充支持，应单独确定范围。

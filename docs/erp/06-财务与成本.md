# 06 财务与成本执行规格

适用 R3。遵循[共同执行约定](README.md)。本规格定义软件中的基础金额事实与核对能力，不规定任意工厂的真实会计政策，也不执行银行支付或税务申报。

## 1. 最小闭环与职责

明确金额依据 → 经审核的应收/应付 → 实际收付款登记 → 分次核销 → 余额核对；业务及反向依据关联基础凭证/账簿；存货/生产成本按可解释来源归集，最后进行期间检查。

财务录入员登记依据和收付款，独立复核员审核/过账/关期；采购、销售和仓管提供业务事实，不借其原权限操作账务。财务金额和 WMS 数量分开持有，财务过账不触发第二次实物收发。

## 2. 基本功能工作包

| 编号 | 功能与最小信息 | 页面/动作 | 依赖与限制 |
|---|---|---|---|
| FIN-01 | 单组织单币种、金额/价格精度与舍入、会计期间、最小科目及结算账户目录、初始化时点、金额依据与计价政策版本 | 基础设置、期初录入/复核、金额依据确认及版本查询 | R1/R2 历史无金额时不得补 0；需选择实际口径或明确标记的演示基线 |
| FIN-02 | 应收/应付：往来方、来源业务及行、依据号、确认金额、日期/期间、已核销/剩余、反向关联 | 依据列表、审核确认、往来明细及来源追溯 | PUR-06/SAL-06；收发数量本身不是最终金额；同一依据只确认一次 |
| FIN-03 | 收付款：方向、往来方、结算账户、登记金额、实际日期、外部凭证参考、状态、审核 | 收付款登记/复核、未分配金额、核销明细 | 登记的是已核对事实，不发起外部交易；可分次、多单分配但不能跨往来方/币种混核 |
| FIN-04 | 应收应付调整、核销撤销及退款责任的关联反向记录 | 退货/纠错依据审核、反向处理、待退款/待重分配查询 | 保留原单，已经收付金额不因退货删除；没有真实退款依据只显示待处理 |
| FIN-05 | 基础凭证、借贷行、来源、审核/过账、账簿发生额及余额、试算检查 | 固定业务映射或受控手工凭证、审核、过账、反向凭证、账簿 | 不建通用会计规则引擎；同源重复不多过账，已过账凭证不可改写 |
| FIN-06 | 存货与生产成本：原数量事实、确认金额、成本归集对象、原成本层/批次关联、人工补充直接费用及审核、分摊结果 | 待计价清单、工单成本明细、成本计算/复核、库存金额核对 | 不用销售价当成本；不把消耗量当金额；有未定来源时保留待计价 |
| FIN-07 | 期间检查：未审依据、未过账、账簿/往来/存货及成本差异、待计价、关期快照 | 期末检查、明确阻断原因、复核关期、历史快照 | 差异未解释不能关期；初版不支持任意反结账，迟到事实按已确认的开放期纠正流程处理 |

## 3. 可以直接执行的公共规则

依据、收付款及凭证均区分草稿、待审、已审核/已过账、已冲正；核销是独立关联事实，不用覆盖“已支付金额”模拟历史。往来单未结额 = 有效确认金额 + 关联调整 - 有效核销；正常正向核销不超过未结额及收付款可分配额。退货导致余额方向变化时列明客户/供应商信用或待退款责任，不截断为零。

跨往来方、跨币种或超额核销拒绝；部分收付款和部分核销保留剩余。反向记录指向原事实；已过账事实不能删除。冲销已核销业务需先核对对应核销及实际收付款，不允许一键抹掉原付款；退款登记和客户退货实收是两件事。

凭证必须借贷平衡、科目和期间有效、来源唯一；过账、账簿变化和审计原子提交。期间关闭后拒绝向该期补写业务凭证，不能为了迟到消息自动反关期。会计/业务日期分开保留，不能通过改日期掩盖迟到事实。

成本只能引用实际取得的金额依据、材料消耗及独立完工量。销售退货回入的成本必须关联原出库成本或明确审核的调整依据；不能按当前售价或当期平均值随意补值。无原成本时进入待计价，不因此伪造零成本或重复改数量库存。

## 4. 实施前必须明确的少量口径

| 事项 | 为什么不能猜 | 执行方式 |
|---|---|---|
| 往来确认时点与金额依据 | 收货、上架、开票、合同约定可能不同 | 在 FIN-01 记录具体来源及确认条件，FIN-02 只按该已审核依据生效；程序不得默认为收货就产生应付 |
| 精度、币种与税额 | 不同币种/工厂规则影响金额 | 初版只支持一种币种和明确精度/舍入；税务申报不做，需要的税额仅按已确认业务口径记录，不自动猜税率 |
| 存货计价和生产成本 | 批次实际成本、平均计价及工时/制造费口径不同 | 只选一种有依据的方法，不同时实现多方法引擎；列明退货/冲正、暂估/待计价和在制品处理 |
| 期初与已结期间纠正 | 旧数量数据不含足够财务依据 | 明确启用日、审核期初及开放期纠正方式；不能对历史数量自动回填真实金额 |

没有实际工厂资料时，可用固定金额的演示数据验证公共约束和流程，但必须标识演示口径。FIN-01 的口径选择及其正常/异常样例是后续过账和成本实现的前置成果；不能绕过它把通用设计当真实财务验收。

## 5. 同编号验收与基本异常

以下金额是程序验收数据，不是工厂默认计价或确认政策。适用 C-01—C-06。

| 编号 | 验收场景与结果 |
|---|---|
| FIN-01 | 已批准初始化才开放金额业务；无金额的历史订单显示待建立依据，不能自动记 0；非法精度、科目/币种或期间拒绝 |
| FIN-02 | 明确依据确认应收 1000，重复/并发确认仍只有 1000；来源不同不能仅凭客户和金额去重；来源撤销不静默删除已确认往来 |
| FIN-03 | 收款 600 分配本应收 400 后，未分配 200、该应收未结 600；再次核销 201 拒绝；并发分配不能超过剩余 200 |
| FIN-04 | 已结清应收退货调整 200，保留原收款/核销并形成 200 待退款或信用责任；没有退款凭证不能标退款完成，重复调整不形成第二笔 |
| FIN-05 | 借贷不平、已结期间、来源重复或自审拒绝；过账重复只增加一次余额；反向凭证关联原凭证，原凭证内容不改 |
| FIN-06 | 已确认材料成本 80、直接费用 20，独立完工 10，指定演示口径下分摊总额保持 100；少依据时进入待计价，不能填 0；退货/冲正按原成本关联不重复计算 |
| FIN-07 | 往来/账簿差异或待计价存在时明确阻断关期；通过检查后保存快照；关期与过账竞争不能产生关期后偷写 |

## 6. 工厂差异与停止条件

初版不做多币种、集团合并、复杂分摊、信用融资、自动银行核对、税务申报或完整法定报表。税票、结算条款、计价、成本分配及期末制度根据具体工厂确认，不预置为通用规则。

停止条件：选定的一种口径下七项基础功能成立，业务依据、往来、收付款、凭证、库存/生产成本和期间可核对，错误有受控反向路径。没有适用口径和成本来源时应如实记录未完成，不以演示算例通过替代真实环境验证。

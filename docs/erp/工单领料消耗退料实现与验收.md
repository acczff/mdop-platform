# 工单领料、消耗与退料（MFG-04）

后续独立切片已接入[完工复核与成品入库](完工复核与成品入库实现与验收.md)。本页保留 MFG-04 当时的范围和验收记录。

范围依据：[生产与物料计划](05-生产与物料计划.md)。本轮连接正式 ERP 工单与已有 WMS 领料、线边消耗、实物退回和双人冲正，不包含完工登记、工单结束、MRP、成本、自动补料和损耗率。

## 数量与职责

- 生产计划员在已批准工单的最新材料计划中选择组件，分次授权领料；累计未取消领料不得超过固定 BOM 的理论需求。首单固定线边仓，供料仓沿用材料计划。
- 每张领料单由仓管选择一个合格、未冻结且未过期的批次，整单预占及发料。发料转入该工单的线边占用，不减少企业总库存。
- 专门的生产记录员登记实际消耗和退料申请，记录事件编号、原因、操作者。仓管确认实际收到退料后回库，待退数量不能再次消耗。
- 未发料单取消释放授权额度；已发料单及历史消耗不可删除。退料不自动恢复授权额度，额外补料留待具体工厂规则明确后处理。
- 合格退料进原料仓存储区；不合格或过期退料进待检区。沿用既有冲正双人审批、原流水追溯和原样重试规则。
- 存在未取消领料单时禁止取消工单，包含已全部消耗或退回的发料单。执行进度独立于工单批准状态，本轮不自动结束工单。

## 计划与来源

重算采购缺口时，扣除本工单已预占量及已发料净额（发料减已退回，含已消耗）；待预占单不重复扣除仓库可用量。新发料、消耗、退料及冲正均使旧采购建议事实快照失效。

正式领料保存工单、材料计划行、物料及仓库引用。正式登记使用独立权限和正式接口，不接受模拟 MES 对正式工单的写入，也不向模拟 MES 发送正式业务反馈。原有模拟流程继续用于明确标记的本地测试。

## 接口、权限与事务

| 动作 | 接口 | 权限及范围 |
|---|---|---|
| 查看材料计划及执行 | `GET /api/v1/manufacturing/orders/{id}/materials` | `manufacturing:read`，工单成品仓及供料仓 |
| 生成领料单 | `POST /api/v1/manufacturing/orders/{id}/materials/issues` | `manufacturing:write`，成品仓、供料仓及目标线边仓；计划版本、组件行、数量、说明、请求键 |
| 预占/发料/取消未发料 | 现有 `/api/v1/wms/issues/{id}/…` | 既有仓管权限与来源/目标仓范围 |
| 登记实际消耗 | `POST /api/v1/wms/production/consumptions` | `wms:production:report`；`consumption` 内含事件号、领料单、工单号、数量，外层 `reason` 必填 |
| 申请退料 | `POST /api/v1/wms/production/returns` | 同上；事件号、领料单、工单号、数量、质量、目标库位、原因 |
| 确认实物退回/冲正 | 现有 WMS 退料及生产冲正接口 | 既有仓管/复核权限与双人规则 |

新增角色 `PRODUCTION_RECORDER`（生产记录员）只有仓库目录、领料/生产读取及生产登记权限，原仓管角色不自动获得登记权限，旧账号也不自动扩权。登记需要供料仓与线边仓范围。生产计划员仍只负责计划授权，不获得消耗登记或仓库过账权限。

跨模块经 common 契约调用，WMS 持有唯一库存账，ERP 读取执行事实。按仓库 ID 顺序加锁，随后获取既有制造保护锁，最后锁领料单与库存；正式发料、消耗、退料和冲正均参加此顺序，工单授权并发与取消保护读取一致事实。发料请求键绑定操作者、工单和完整载荷；人工登记事件号绑定来源、数量、原因及记录人。确定业务拒绝允许修正输入；超时、服务异常和失效会话保留原请求，前端在当前账号/单据下恢复原样重试。

迁移 `202610110001` 新增工单线边仓、领料正式来源外键及人工登记来源/原因字段，不新增库存表；当前 37 项迁移、79 张表。历史领料来源保持空值，历史登记默认 `SIMULATED`，不认领为正式工单。升级前备份，保留旧表和旧快照；日常环境升级属于独立交付动作。

# 完工复核与成品入库（MFG-05）

范围依据：[生产与物料计划](05-生产与物料计划.md)。本轮在 [MFG-04](工单领料消耗退料实现与验收.md) 之上接通实际完工登记、独立复核与既有成品待检/上架，不包含 MFG-06 工单结束、返工报废、成本或真实 MES/QMS 接入。

## 最小流程

生产记录员在已批准工单中填写稳定报告号、本次实际完工数量、批次、生产日期、适用的 Date Code/有效期与依据，提交即进入待复核。产品、单位和成品仓继承工单授权，不允许自由改写。生产日期按业务日期显示，不转换为 UTC 时间。

另一名生产审批员批准或驳回。登记人只能撤销本人待复核报告，不能自审；驳回、撤销的原报告保留，新登记使用新的报告号。批准时事务内生成唯一 WMS 成品入库需求，报告和下游创建一起提交或回滚。

仓管确认实物收到成品仓待检位后增加待检在手量，可用量仍为零。明确模拟的 QMS 判定合格后仍待上架，仓管确认正式库位后才增加可用量；不合格保持隔离，过期成品不能判为合格或上架。首版每张报告整单收货、整批判定、整单上架；需要混合质量时使用分别可追溯的报告/批次，不在本轮实现拆分处置。

## 数量、异常与来源

- 待复核量 + 已批准量不得超过工单授权产量；同仓锁及制造保护锁串行保护并发登记和工单取消。复核只将已占额度转为已批准额度，不重复累计。
- 实际完工量是独立事实，不由消耗量、BOM 或计划日期反推；本轮不强制材料清零，不将上架当作工单结束。
- 存在待复核或已批准报告时禁止普通取消工单。批准后不能撤销、修改数量或自动恢复额度，错误报告及不合格实物保留待处理，后续处置须单独确定范围。
- 报告号唯一；请求键绑定动作、工单、完整载荷与操作者。同键原样重试返回当前结果，不重复建单；同号另建、同键变更内容及旧版本动作拒绝。
- 前端按账号和工单保留未知请求；网络异常和 401/403/503 不换键。读取失败不保留可操作旧记录；浏览器存储失败停止新写入。
- 成品入库保存正式工单和完工报告外键。正式来源拒绝模拟 MES 建单；保留模拟 QMS 检验请求，不产生模拟 MES 收货/上架反馈。旧模拟流程及请求摘要保持兼容。

## 接口与权限

| 动作 | 接口 | 权限 |
|---|---|---|
| 完工数量与报告查询 | `GET /api/v1/manufacturing/orders/{id}/completions` | `manufacturing:read` |
| 提交完工登记 | `POST /api/v1/manufacturing/orders/{id}/completions` | `manufacturing:completion:report` |
| 批准/驳回 | `POST …/completions/{reportId}/approve`、`reject` | `manufacturing:completion:review`，与登记人不同 |
| 撤销待复核登记 | `POST …/completions/{reportId}/cancel` | `manufacturing:completion:report`，限本人报告 |
| 实物收货/上架 | 现有 `/api/v1/wms/finished-receipts/{id}/receive`、`putaway` | 现有 WMS 仓管权限 |
| 模拟质量判定 | 现有 `/api/local/finished-receipts/{id}/quality` | 仅 local/test 模拟权限 |

所有正式完工读写核对工单成品仓范围，系统管理员无业务绕过。生产记录员角色增加生产查询和完工登记；生产审批员角色增加完工复核，两角色不能合并配置。现有账号保存的是明确权限，不自动扩权；需要登记或复核时由系统管理员重新分配对应职责。仓管与计划员不默认获得完工登记/复核权。

## 迁移与模块边界

新增 `202610110002`：`mfg_completion` 保存事实、状态、登记及处理人/时间/原因，`mfg_completion_command` 保存幂等凭据；`wms_finished_receipt` 增加成对正式来源外键和唯一报告引用。共 38 项迁移、81 张表，旧入库来源为空，历史内容不认领为正式工单。

制造通过 common 的 `ProductionCompletionPort` 请求 WMS 建单并读取实物状态，库存数量账只在 WMS。批准先锁成品仓、再制造保护锁；下游收货/上架沿用仓库与库存锁。当前同应用数据库事务保证批准和建单原子性，不新增模拟消息审批状态机。

## 验收记录

本轮记录日期：2026-10-11。最终数量、浏览器覆盖、升级和 CI 证据见[版本记录](../project/status.md)。核心自动回归覆盖：

- 工单授权 10，报告 6+4，独立批准后分别生成有来源入库单；第 11 件拒绝。
- 待检和合格待上架均不可用；上架后才可用，重复确认保持单套流水。
- 两个并发 6 件报告只能成功一个；驳回/撤销释放待复核额度。
- 自审、越仓、角色越权、缺少 CSRF、日期或批次异常拒绝，无半成品入库单。
- 不合格与过期隔离；批准后禁止取消，正式工单禁止模拟 MES 建单。
- 未知响应原样恢复、只读展示、失效会话及迟到读取保护。
